#  MshMsh POS - Enterprise Point of Sale System

A commercial-grade Point of Sale (POS) desktop application engineered using C#, Windows Forms (.NET), and Entity Framework Core (SQL Server) following Clean Architecture principles.

##  Key Features
- Security & RBAC: Role-Based Access Control (Admin & Cashier sessions).
- Point of Sale (POS): Barcode scanner support, smart search, instant customer selection, custom discounts, and receipt printing.
- Inventory Management: Full CRUD operations with duplication prevention validations and barcode label printing.
- Financial Analytics: Real-time calculation of Sales, Costs, Refunds, and Net Profits with customizable date range filters.
- Partial Returns Workflow: Dedicated return module linked directly to stock inventory.
- Customer CRM: Customer purchase history and transaction logging.

##  Built With
- C# & Windows Forms (.NET)
- Entity Framework Core (Code-First)
- Microsoft SQL Server
